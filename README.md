# AI-продавец Eco-Store

MVP внешнего AI-консультанта для Открытых линий Bitrix24.

## Что уже умеет ядро

- хранит состояние диалога и известные параметры клиента;
- определяет запрос, город, размеры, бюджет, срок, раму и подсветку;
- выбирает следующий этап воронки;
- различает путь с визуализацией и расчёт без визуализации;
- формирует безопасный контекст для нейросети из базы скриптов;
- работает в `shadow`-режиме: сохраняет предлагаемый ответ, но не отправляет его клиенту;
- поддерживает OpenAI-совместимые API (DeepSeek и другие).

## Быстрый локальный запуск

```powershell
Copy-Item .env.example .env
python -m ai_seller.server
```

По умолчанию сервер слушает `http://127.0.0.1:8080`.

Проверка:

```powershell
Invoke-RestMethod http://127.0.0.1:8080/health
```

Тест сообщения:

```powershell
$body = @{conversation_id='demo-1'; text='Здравствуйте, хочу панно 2 на 1 метр в Казань'} | ConvertTo-Json
Invoke-RestMethod http://127.0.0.1:8080/test/message -Method Post -ContentType 'application/json' -Body $body
```

## Режимы

- `shadow` — ответ сохраняется и возвращается в API, клиенту ничего не отправляется;
- `auto` — разрешена отправка через Bitrix24 после подключения и проверки.

До окончания тестов оставлять `APP_MODE=shadow`.

## Подключение Bitrix24

Нужны публичный HTTPS-адрес сервиса, входящий вебхук/локальное приложение с правами `crm`, `im`, `imbot`, `imopenlines`, идентификаторы стадий и коды пользовательских полей. Секреты хранятся только в `.env`.
