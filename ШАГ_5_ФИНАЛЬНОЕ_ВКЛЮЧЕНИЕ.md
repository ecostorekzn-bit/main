# ШАГ 5: Финальное включение AI-продавца на боевые каналы

**⚠️ ВЫПОЛНЯТЬ ТОЛЬКО ПОСЛЕ УСПЕШНОГО ТЕСТА ШАГА 4**

Этот шаг переводит бота из режима `shadow` (только логирование) в режим `auto` (реальные ответы клиентам) и включает его на главный канал MAX (линия 12).

---

## ЧАСТЬ 1: Переключение режима на AUTO

### Шаг 1.1: Отредактируй .env

Открой файл `.env` и найди строку:
```
APP_MODE=shadow
```

Замени на:
```
APP_MODE=auto
```

**Сохрани файл.**

---

### Шаг 1.2: Пересобери конфиг для хостинга

В командной строке, в папке проекта, выполни:

```bash
python scripts/build_hosting_config.py
```

Ожидается: скрипт молча завершится, без ошибок.

---

### Шаг 1.3: Залей конфиг на сервер

Выполни:

```bash
python scripts/ftp_upload.py deploy/runtime/ai_seller_config.php .. ai_seller_config.php
```

Ожидается: сообщение вроде `Uploaded ai_seller_config.php to /wordpress_eco/`

---

### Шаг 1.4: Проверь, что сервер живой

Выполни (копируя токен из .env):

```bash
curl "https://eco-store16.ru/ai-seller/index.php?action=health&token=[ТОКЕН]"
```

Должен вернуться JSON вроде:
```json
{
  "ok": true,
  "mode": "auto",
  "php": "7.4.33",
  "bitrix_ok": true,
  "knowledge_ok": true
}
```

**Важно:** убедись, что `"mode": "auto"`, а не `"shadow"`.

Если режим всё ещё `shadow`, значит конфиг не загрузился. Переделай шаги 1.2 и 1.3.

---

## ЧАСТЬ 2: Назначение бота приветственным на линию 12 (MAX)

### Шаг 2.1: Получи ID бота и webhook-адрес Bitrix

Открой `.env` и найди:
- `BOT_ID` (пример: `19354`)
- `BITRIX_WEBHOOK_BASE` (пример: `https://eco-store16.ru/rest/1/...`)

Запомни эти значения.

---

### Шаг 2.2: Отправь запрос к Bitrix API

Выполни curl-команду (замени `[WEBHOOK]` на значение из `BITRIX_WEBHOOK_BASE`):

```bash
curl -X POST "[WEBHOOK]/imopenlines.config.update" \
  -H "Content-Type: application/json" \
  -d '{
    "OPEN_LINE_ID": 12,
    "WELCOME_BOT_ENABLE": "Y",
    "WELCOME_BOT_ID": 19354,
    "WELCOME_BOT_JOIN": "always",
    "WELCOME_BOT_LEFT": "queue"
  }'
```

**Пояснение параметров:**
- `OPEN_LINE_ID: 12` — это линия MAX (не трогай 4 и 10, это ВК и Avito)
- `WELCOME_BOT_ENABLE: Y` — включить бота
- `WELCOME_BOT_ID: 19354` — ID нашего бота (Алина Eco-Store)
- `WELCOME_BOT_JOIN: always` — бот присоединяется к каждому новому диалогу
- `WELCOME_BOT_LEFT: queue` — бот уходит, когда диалог берёт оператор

---

### Шаг 2.3: Проверь результат

Ожидается JSON ответ типа:
```json
{
  "result": true
}
```

или

```json
{
  "result": {
    "OPEN_LINE_ID": 12
  }
}
```

Если вернулась ошибка — переделай команду, проверь webhook-адрес и ID бота.

---

### Шаг 2.4: Убедись в Bitrix, что бот назначен

Открой Bitrix24 → Администратор → Открытые линии → вкладка Мессенджеры (линия 12).

В разделе "Приветственный бот" должно быть:
- Бот: **Алина Eco-Store** (или название нашего бота)
- Статус: **Включён**
- Присоединяется: **Всегда**
- Уходит: **Когда оператор берёт диалог**

Если галочки стоят правильно — ✅ готово.

## ФИНАЛЬНАЯ ПРОВЕРКА

После включения бота на боевые каналы:

### 1. Проверь health-check
```bash
curl "https://eco-store16.ru/ai-seller/index.php?action=health&token=[ТОКЕН]"
```

Должен быть `"mode": "auto"` и `"ok": true`.

### 2. Смотри в журнал первые реальные диалоги

Новые сообщения от клиентов будут приходить в диалоги на линии 12 (MAX). Бот должен:
- Присоединяться автоматически
- Отвечать клиентам
- Не повторять вопросы
- Молчать, если пишет менеджер

### 3. Если что-то не так

**Бот не отвечает:**
- Проверь, что `"mode": "auto"` в health-check
- Убедись, что бот назначен приветственным в Bitrix
- Жди 1-2 минуты на обновление кэша Bitrix

**Бот отвечает неправильно:**
- Проверь журнал: `?action=debug_recent&token=[ТОКЕН]&conversation_id=chatNNNN`
- Посмотри на поле `reply_source` — откуда бот взял ответ
- Если `source: llm_text` — ошибка в LLM-модели, свяжись с Yandex AI Studio

**Менеджер не может взять диалог:**
- Убедись, что в конфиге `WELCOME_BOT_LEFT: queue`
- Если оператор нажимает "Взять диалог", бот должен уйти

## Если нужно вернуться обратно на SHADOW

Если тест не прошёл и нужно откатиться:

### 1. Отредактируй .env
```
APP_MODE=shadow
```

### 2. Пересобери и залей конфиг
```bash
python scripts/build_hosting_config.py
python scripts/ftp_upload.py deploy/runtime/ai_seller_config.php .. ai_seller_config.php
```

### 3. Отключи бота в Bitrix
```bash
curl -X POST "[WEBHOOK]/imopenlines.config.update" \
  -H "Content-Type: application/json" \
  -d '{
    "OPEN_LINE_ID": 12,
    "WELCOME_BOT_ENABLE": "N"
  }'
```

---

## Важно помнить

- 🔴 **Не переключайся на `auto` без успешного теста**
- 🔴 **Не открывай и не печатай .env, webhook-адреса, ключи API**
- 🟡 **После включения на MAX первые 30 минут смотри, как бот отвечает реальным клиентам**
- 🟡 **Если начнутся ошибки, есть кнопка выключения через `?action=stop_bot&token=...`**
- 🟢 **Линии 4 (ВК) и 10 (Avito) подключай только после того, как MAX отработал без ошибок, отдельно и с согласованием**
