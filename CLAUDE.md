# Eco-Store AI-продавец — инструкция для Claude

Сначала полностью прочитай `HANDOFF.md`, затем работай с текущим кодом, не создавая интеграцию заново.

## Главная цель

За минимальное число итераций довести AI-менеджера до запуска: стабильная переписка в MAX/открытых линиях Bitrix24, память диалога, голосовые сообщения и одно PDF-КП с несколькими изделиями.

## Критические ограничения

- Постоянный тестовый диалог: `chat24310`, сделка `28494`, Алина WEB.
- Никогда не отключай бота в `chat24310`.
- После каждой отправки сам прочитай реальную историю Bitrix и проверь фактический текст.
- Не проси Алину пересказывать ответ бота: смотри историю и журналы самостоятельно.
- Не отправляй сообщение, если оно повторяет предыдущий вопрос или игнорирует вопрос клиента.
- Не раскрывай `.env`, вебхуки, API-ключи и FTP-доступ.
- Не меняй рабочие сайт, формы и существующие вебхуки без прямой необходимости.
- Все изменения сначала локально, затем загрузка через `scripts/ftp_upload.py`.

## Приоритеты

1. Сократить расходы: передавать модели карточку фактов и последние 4–6 реплик вместо длинной истории; короткий ответ; не вызывать LLM для технических событий.
2. Проверить голосовой запрос с несколькими изделиями.
3. Сформировать одно КП с несколькими вариантами/размерами.
4. Проверить сообщения подряд, работу вечером и сохранение контекста.
5. Только после этого включать один реальный канал.

## Стиль продавца

Коротко, живо, профессионально. Сначала ответить на вопросы клиента, потом задать максимум один следующий вопрос. Не использовать дефисы и длинные тире. Допустимы скобочные смайлики. Не писать клиенту, что отвечает бот, и не утверждать, что отвечает живой человек.

## Быстрый старт

1. Открой корень проекта.
2. Прочитай `HANDOFF.md`.
3. Проверь `git diff` или сравни актуальные файлы.
4. Получи последние сообщения `chat24310` через `ai_seller.bitrix.BitrixClient`.
5. Проверь `debug_recent` продакшена.
6. Исправляй ошибки пакетно, а не по одной фразе.

Локальный `.env` может присутствовать только в закрытой копии проекта. Никогда не цитируй его содержимое в ответах или логах.
