# Карта подключения Bitrix24

## Стадии

В `.env` нужно записать не видимые названия, а системные `STATUS_ID`:

| Переменная | Стадия |
|---|---|
| `BITRIX_STAGE_NEW` | Новая заявка |
| `BITRIX_STAGE_NEEDS` | Выявление потребности |
| `BITRIX_STAGE_VISUAL` | Сделать визуал |
| `BITRIX_STAGE_CALC` | Готовим расчёт |

## Поля сделки

| Переменная | Поле |
|---|---|
| `BITRIX_FIELD_REQUEST` | Запрос клиента |
| `BITRIX_FIELD_OBJECT_PHOTO` | Фото объекта, тип Файл, желательно множественное |
| `BITRIX_FIELD_REFERENCE` | Референс клиента, тип Файл, множественное |
| `BITRIX_FIELD_LOGO` | Логотип, тип Файл, множественное |

Дополнительно рекомендуется создать поля: размер, город, срок, бюджет, рама, подсветка, тип изделия, результат квалификации и причина передачи менеджеру.

## Правила переходов

1. Заполнен «Запрос клиента» -> «Выявление потребности».
2. Подтверждено фото объекта -> файл в карточку -> «Сделать визуал».
3. Клиент требует цену без визуала, известны изделие и размер -> «Готовим расчёт».
4. Неизвестное изображение не меняет стадию: AI сначала уточняет назначение файла.

## Безопасное подключение

Не отправлять секрет вебхука сообщением. Его нужно вставить локально в `.env` в `BITRIX_WEBHOOK_BASE`. Начинать только с `APP_MODE=shadow`.
