ПРОВЕРКА ХОСТИНГА

1. В панели хостинга создайте папку ai-test внутри сайта eco-store16.ru.
2. Загрузите в неё файл hosting_check.php.
3. Откройте https://eco-store16.ru/ai-test/hosting_check.php
4. Пришлите результат JSON или только ссылку.
5. После проверки файл и папку ai-test нужно удалить.

Файл не содержит паролей, ключей или данных Bitrix24.
